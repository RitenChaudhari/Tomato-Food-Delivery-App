# Food-Delivery Website
  Inspired from Swiggy , from this website user can add items to the cart,delete it using + and - signs<br />
  and when checking Out, the user will be authenticated using JWT web token.<br/>
  and It also has a Admin Panel , from where the admin can manage the menu.<br/>

## Tech Stack Used: <br/>
  ### Frontend : ReactJS, Vanilla CSS <br/>
  ### Backend : NodeJS,ExpressJS <br/>
  ### Database : MongoDB <br/>
  ### Payment Processing: Stripe (npm package) <br/>
